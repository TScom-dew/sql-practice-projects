The goal of this repository is to bridge the gap between theoretical SQL concepts and real-world data analysis problems. Each mini-project simulates a business role (such as a Data Analyst or Database Administrator) to solve specific data-driven queries.

## How to Run Locally
If you want to run or test these SQL scripts on your local machine using MySQL and VS Code:

1. Clone the repository:
  ```
  git clone https://github.com/TScom-dew/sql-practice-projects.git
  ```
  

2. Open the folder in VS Code.

3. Install a MySQL extension in VS Code (like MySQL or SQLTools).

4. Run the `schema.sql` file in your local MySQL server to set up tables and insert sample data.

5. Explore and execute queries from `queries.sql`.
